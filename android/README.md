# «Глазомер» для Android (RuStore)

Приложение — один экран со встроенным браузером, в котором открыта игра из корня репозитория.
Файлы игры копируются в сборку как есть; подменяется только `platform.js`: вместо SDK Яндекс Игр — `app/src/main/web/platform.js` (без рекламы и облака, итог партии уходит в системное «Поделиться»).
Разрешений у приложения нет, в сеть оно не ходит. Сохранение — localStorage встроенного браузера.

## Сборка

Нужен JDK 17–21 (подходит тот, что внутри Android Studio) и `local.properties` с путём к Android SDK.

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

Релиз подписывается ключом из `keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`). Ни он, ни сам ключ в репозиторий не попадают. Потерять ключ — значит потерять возможность обновлять приложение в магазине: храните копию отдельно.

Перед новой загрузкой в магазин поднимите `versionCode` в `app/build.gradle.kts`.

## Тесты

```bash
./gradlew testDebugUnitTest
```

Состав сборки: страница подключает только то, что в неё попало, файлы совпадают с корнем репозитория, ссылок в сеть нет, обёртка площадки умеет всё, что игра у неё просит.

```bash
./gradlew connectedDebugAndroidTest
```

Игра на устройстве или эмуляторе: тесты нажимают кнопки настоящими касаниями — обучение, партия дня во всех трёх режимах, подсказки, сохранение после перезапуска, системная «назад», «Поделиться», вёрстка без прокрутки. Идут около четырёх минут.

```bash
./gradlew connectedReleaseAndroidTest -PtestRelease
```

То же на релизной сборке со сжатием кода.

## Значок

Слои значка рисует `promo/app-icon.html` (432×432: без параметра — весы, `?bg` — бумага); снимки лежат в `app/src/main/res/mipmap-xxxhdpi`.
